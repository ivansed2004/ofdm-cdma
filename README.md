## Множественный доступ с кодовым разделением (CDMA)

Метод множественного доступа, основанный на прямом последовательном расширении спектра (DSSS) ортогональными или квазиортогональными псевдослучайными последовательностями. 

**Принцип работы**: Каждому пользователю сети выделяется своя уникальная последовательность, различимая среди других. Выделение нужной последовательности осуществляется с помощью корреляционной обработки: благодаря низким взаимным корреляциям с другими последовательностями конкретная последовательность может быть выделена в корреляторе (согласованном фильтре) и определена по оценке максимального правдоподобия - максимального SNR.

**Ключевые особенности**:
1. **Помехозащищенность**. Расширение спектра распределяет энергию сигнала по широкой полосе, что делает его менее уязвимым к узкополосным помехам.
2. **Конфиденциальность**. Определить содержание переданной информации возможно только зная исходную последовательность, известную только базовой станции и мобильному телефону.
3. **Борьба с многолучевым распространением**. Использование RAKE-приемников для обработки каждого задержанного компонента сигнала отдельно. Позволяет повысить SNR путем сложения всех многолучевых компонент, пришедших с разных приемников.

**Применение**: Метод является основой для систем спутниковой связи, а также систем позиционирования. Имеет место в ныне выводящихся из эксплуатации системах сотовой связи 3G.

## Ортогональное частотное разделение каналов (OFDM)

Представляет собой метод разделения каналов по частотам. Однако в отличие от стандартного частотного разделения (FDMA), где каждый канал отделен защитным интервалом, в OFDM происходит частичное перекрытие каналов.

**Принцип работы**: Ортогональное размещение поднесущих в спектре: пиковое значение некоторой поднесущей приходится на нули остальных поднесущих на данной частоте, что гарантирует отсутствие межканальной интерференции даже при частичном перекрытии поднесущих.

**Ключевые особенности**:
1. **Цифровая обработка**: Благодаря FFT/IFFT возможна реализация OFDM цифровым способом в DSP/FPGA. Достаточно представить комплексные I/Q-отсчеты в виде дискретного ряда.
2. **Помехозащищенность**: Искажение отдельных поднесущих в условиях замираний не лишает возможности ее сохранить в остальных, не подвергнувшихся этим замираниям.
3. **Циклический префикс**. Для решения проблемы синхронизации, а также многолучевого распространения применяется специальная последовательность: она представляет собой копию некоторой части конца текущего символа, вставленного в начало, имитируя тем самым циклический характер передачи.
4. **Спектральная эффективность**. Вместо передачи символа модуляции на одной широкой несущей происходит параллельная передача множества символов по узким поднесущим.

### DCO-OFDM vs ACO-OFDM
Высокий пик-фактор в DCO-OFDM создает большую по величине постоянную составляющую, что вынуждает повышать мощность сигнала. При этом эта составляющая не несет дополнительной информации, а просто смещает точки OFDM-фрейма. Преимущество использования ACO-OFDM заключается в отсутствии постоянной составляющей, а также ограничении сигнала только положительной полуплоскостью, обнуляя четные поднесущие и сокращая общую энергию сигнала в два раза.

**Применение**: Является основой современных систем радиосвязи от беспроводных локальных сетей (IEEE 802.11) до сетей сотовой связи (LTE, 5G), а также оптических систем связи.

## Код Голда

**Построение**: Осуществляется в регистре сдвига с линейной обратной связью путем выбора характеристического полинома $g(x)$. Степень полинома $n$ определяет длину последовательности, равной $2^n-1$. Генерация ансамбля может быть выполнена путем XOR двух заведомо различных псевдослучайных последовательностей с последующим циклическим сдвигом одной из них, как это делается в данном проекте. Количество последовательностей в ансамбле кода, таким образом, достигает $2^n+1$.

**Свойства**:
1. Псевдослучайный характер обеспечивает низкие взаимные корреляции между двумя отдельными последовательностями.
2. Любой сдвиг одной и той же последовательности относительно той же самой приводит по сути к появлению новой последовательности.

**Применение**: Активно применяется в радиолокационных системах, системах спутниковой связи и навигации. В соответствии с 3GPP TS 38.211 последовательности Голда применяются в системах мобильной сотовой связи 5G в качестве сигналов вторичной синхронизации (SSS).

## Код Уолша

**Построение**: Может быть построен с использованием рекурсивной матрицы Адамара путем кронекеровского произведения этой матрицы с самой собой. Каждая строка/столбец представляет собой ортогональный по отношению к остальных код.

**Свойства**:
1. Ортогональность на интервале корреляции.

**Применение**: Активно применялся в стандартах мобильной связи 3G (WCDMA) в качестве кодового ресурса для разделения пользователей (множественный доступ с кодовым разделением, CDMA).
